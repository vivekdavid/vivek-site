🛠️ How to use

Just copy this pattern: 

<ol class="emoji-list">
  <li data-emoji="🔥">Your first item</li>
  <li data-emoji="✨">Your second item</li>
  <li data-emoji="🎯">Your third item</li>
</ol>
Tip: Add the class emoji-only if you want just the emoji without the number.
Drop this file into any project — no build step required.
